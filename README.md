# پروژه آزمایشی خرید و فروش طلا (Gold Order)

یک برنامه ساده برای نمایش موجودی و ثبت سفارش خرید یا فروش طلا.

## فناوری‌ها

- **بک‌اند:** Laravel و PHP-FPM
- **فرانت‌اند:** Next.js و React
- **دیتابیس:** MySQL 8.4
- **زیرساخت:** Docker Compose و Nginx

## اجرای پروژه

**پیش‌نیاز:** Docker و Docker Compose. برای اجرای معمول پروژه نیازی به نصب جداگانه PHP، Node.js یا MySQL نیست.

از پوشه اصلی پروژه اجرا کنید:

```bash
docker compose up
```

در اولین اجرا، Imageها ساخته/دریافت می‌شوند و Migrationها و Seeder لاراول به‌صورت خودکار اجرا می‌شوند.

- **رابط کاربری:** http://localhost:3000
- **API لاراول:** http://localhost:8000

برای اجرای پس‌زمینه از `docker compose up -d` و برای توقف از `docker compose down` استفاده کنید. برای ساخت مجدد پس از تغییر کدها: `docker compose up --build`.

> اطلاعات MySQL در Volume نگهداری می‌شود؛ از `docker compose down -v` فقط زمانی استفاده کنید که قصد حذف داده‌ها را دارید.

## کاربران آزمایشی

Seeder دو کاربر و کیف پول اولیه می‌سازد:

| کاربر | شناسه در دیتابیس تازه | موجودی ریالی | موجودی طلا |
|---|---:|---:|---:|
| Demo User 1 | 1 | 100,000,000 ریال | 5 گرم |
| Demo User 2 | 2 | 50,000,000 ریال | 2.5 گرم |

در فرانت‌اند می‌توان بین کاربران آزمایشی جابه‌جا شد. Seeder در اجرای مجدد، موجودی کیف پول‌های موجود را بازنویسی نمی‌کند. شناسه‌ها در دیتابیس دارای داده قبلی ممکن است متفاوت باشند.

## APIها

درخواست‌ها باید هدر `X-User-Id` داشته باشند؛ ورود و ثبت‌نام در این آزمون وجود ندارد.

| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/api/wallet` | دریافت موجودی ریالی و طلای کاربر |
| `POST` | `/api/orders` | ثبت سفارش خرید (`buy`) یا فروش (`sell`) |

نمونه ثبت سفارش:

```bash
curl -X POST http://localhost:8000/api/orders \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H 'X-User-Id: 1' \
  -d '{"type":"buy","amount":"0.5","price":"10000000"}'
```

در این درخواست، `amount` مقدار طلا **به گرم** و `price` قیمت **هر گرم به ریال** است.

## فرضیات و تصمیم‌های فنی

- قیمت هر گرم را کاربر هنگام ثبت سفارش وارد می‌کند؛ دریافت نرخ لحظه‌ای طلا و درگاه پرداخت در محدوده این آزمون نیستند.
- مبالغ ریالی به‌صورت عدد صحیح و مقدار طلا با حداکثر **۶ رقم اعشار** نگهداری می‌شود. مبلغ سفارش به نزدیک‌ترین ریال با روش `HALF_UP` گرد می‌شود.
- محاسبات مالی بک‌اند با **BCMath** انجام می‌شوند. برای جلوگیری از منفی شدن موجودی، ثبت سفارش و تغییر موجودی در یک **تراکنش دیتابیس** همراه با `lockForUpdate` انجام می‌شود.
- هدر `X-User-Id` فقط برای شبیه‌سازی کاربر در این آزمون است و **روش احراز هویت امن برای محیط واقعی نیست**.
- تنظیمات Docker برای **اجرای محلی و ارزیابی پروژه** است، نه استقرار مستقیم یک سامانه مالی واقعی.
